# pit-outbound-test

Sandbox repository owned by **pit-agent-bot**, the automated machine account operated by Pit.

It exists to test Pit's outbound reply pipeline end to end on a repository the machine account owns itself:
an issue is opened here, holder AIs build and check a small deliverable, and the pipeline posts one reply.
Nothing here is a product; issues and comments may be deleted as part of the test.

- `site/` - a small static Unix epoch converter page (no external scripts, no tracking).
